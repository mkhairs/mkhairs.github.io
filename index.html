Featured Undergraduate Thesis Research

Bitcoin Price Prediction Model Using Gated Recurrent Unit (GRU) & NADAM Optimizer

Engineered a deep learning sequential pipeline for cryptocurrency forecasting across 4,000+ data points (2014-2025). Optimized architecture using Optuna TPE (100 trials) and NADAM optimizer with Huber Loss to mitigate severe market volatility spikes.

1. Data Pipeline

4,000+ closing prices transformed into 7-day lag windows structured by Autocorrelation Function (ACF).

2. Architecture Tuning

Optuna Tree-Structured Parzen Estimator (TPE) algorithm tuned hidden units and learning rates across 100 trials.

3. Robust Loss

Nesterov-accelerated Adaptive Moment Estimation (NADAM) + Huber Loss for outlier robustness.
